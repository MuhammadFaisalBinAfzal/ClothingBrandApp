# Clothing Brand Manager 👕📈

A modern, desktop-based Point of Sale (POS) and Inventory Management application built with Python and CustomTkinter. 

## Features
* **Inventory Management:** Add, update, and categorize clothing products.
* **Point of Sale (POS):** Process sales with real-time stock deductions.
* **Expense Tracking:** Log daily business expenses.
* **Business Reports:** Automatically generate and export financial reports (CSV, PNG, PDF) using Matplotlib.
* **Database:** Robust backend powered by Microsoft SQL Server (`pyodbc`).

## Prerequisites
* Python 3.8+
* Microsoft SQL Server (and ODBC Driver 17)
